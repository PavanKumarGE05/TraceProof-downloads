# TraceProof – downloads

**TraceProof** tests your Snowflake and dbt pipelines CTE by CTE – see where every record goes, why counts change
and what to fix.

This repository only holds the TraceProof installer. The source code is not public.

## Download

**[Download TraceProof for Windows](https://github.com/PavanKumarGE05/TraceProof-downloads/releases/latest/download/TraceProof-Setup.exe)**
– the newest version · Windows 10 / 11, 64-bit

All versions and their checksums: [Releases](https://github.com/PavanKumarGE05/TraceProof-downloads/releases)

## Install

1. Run `TraceProof-Setup.exe` and accept the licence agreement.
2. If Windows says *"Windows protected your PC"*, click **More info → Run anyway**.
3. Open **TraceProof** (or **TraceProof Demo** to try it with demo data) from the desktop or the Start menu.
