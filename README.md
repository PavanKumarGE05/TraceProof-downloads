## Install

1. Run `TraceProof-Setup.exe` and accept the licence agreement.
2. If Windows says *"Windows protected your PC"*, click **More info → Run anyway**.
3. Want a quick look first? Open **TraceProof Demo** – demo data, nothing to set up.
4. Open **TraceProof**. On the first start it asks for your **admin code**: fill in your name, company and e-mail and
   send the request to **saitechlab11@gmail.com**. You receive the admin code by e-mail; paste it, choose a password –
   you are the admin of your TraceProof and can invite your team.

## Licence

- Every installation starts with a **free 14-day trial** once its admin account is created.
- To buy a licence: in TraceProof open **Users & Sign-in → Licence → Ask for a licence** and send the request code
  to **saitechlab11@gmail.com**. You receive a licence key for your installation.
